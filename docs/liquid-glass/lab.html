What this demonstrates

A bounded center uses a critically damped spring after release. A second spring responds to velocity changes and edge pressure. Coupled footprint and thickness scales preserve approximate cap volume. The contacting edge stays pinned during compression. Expansion changes the target geometry without queuing a separate flourish. This is a small Localica proposal, not Apple's code, a fluid-volume simulation, or a production glass shader. The drawing intentionally uses simple gradients so you can focus on behavior.
