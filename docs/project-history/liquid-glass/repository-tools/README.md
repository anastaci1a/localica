# One-time extraction tooling

These scripts record the performed migration, including original absolute source and backup paths. They are not a portable research pipeline or a command to rerun against active source. The extraction ran ONLY in disposable history-extraction.git, never in Localica. git-filter-repo 2.47.0 was pinned in the Dockerfile. Read research/provenance/README.md before any use.

No tool contacts or controls sessions.

The repeated public branch histories are intentional; they preserve unmerged research. Indexed scientific evidence is retained with source hashes and redistribution exclusions.
