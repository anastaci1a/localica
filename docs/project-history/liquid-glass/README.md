# Archived Liquid Glass project records

Historical application integration and repository-separation records belong to this project. They are not current product contracts.

| Records | Purpose |
| --- | --- |
| `repository-records/` | Historical source refs, commit maps, file inventories and verification. |
| `repository-tools/` | One-time administrative scripts; do not run against active worktrees. |
| `application-guide/` | Former application-specific visual and interaction rules. |
| `application-captures/` | Application integration snapshots and issue records. |

Current mathematical research is maintained separately at [Liquid Glass](https://github.com/anastaci1a/liquid-glass). Research inputs, numerical evidence and physical models remain there.

Historical paths and instructions describe their recorded runs. They confer no current execution or session-management authority.
