# Documentation map

Each topic has one home. Follow links for related rules instead of copying them.

| Document | Owns |
| --- | --- |
| [Product](product.md) | Scope, library/queue semantics, file safety, lyrics sources, and statistics rules. |
| [Interface](interface.md) | Layout, gestures, navigation, selection, and UI settings/defaults. |
| [Structure](structure.md) | Code boundaries, persistence, concurrency, rendering, and technical constraints. |
| [Roadmap](roadmap.md) | Next outcomes and deferred capabilities; no release history or ticket inventory. |
| [Build](build.md) | Verification, compatibility caveats, signing, release preparation, and preview capture. |
| [Liquid Glass field guide](https://github.com/anastaci1a/liquid-glass) | Apple evidence, material/motion specification and interactive studies. |
| [Working instructions](../agents/README.md) | Agent workflow, document maintenance, issues, labels, and commits. |

The [root README](../README.md) is the public introduction. Product, Interface and Structure describe the checked-out branch's contracts, not a list of verified or shipped fixes. [Releases](https://github.com/anastaci1a/localica/releases) identify distributed builds; PR evidence identifies tested candidates. An open component PR may already be included in a cumulative branch: inspect ancestry/diffs and exact-source evidence before integrating it again. [Issues](https://github.com/anastaci1a/localica/issues) own acceptance and unresolved defects; the roadmap owns future outcomes. The Liquid Glass guide separates Apple evidence, Localica requirements and experimental models.
