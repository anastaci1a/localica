Refraction study

The lab samples an original backdrop through two selectable inverse-map models. WebGL and software rendering both apply refraction; the status line identifies the active renderer. Compare edge displacement, thickness, blur, contrast and synthetic reflection independently. Its coordinate diagnostic and reproducible browser tests check actual shader output. Run and verify.

Scope

The specification defines the shared system and its acceptance checks. Physical-device performance still needs review; optical materialization remains deferred. Current selection lenses intentionally appear immediately; their entrance motion awaits #107. Requested glass-on-content and nested controls remain explicit departures from Apple's usual layer guidance.

Update evidence and specification together when guidance or owner decisions change; source review dates live in the atlas. Keep release history in Git and Releases. The lab and its captures are original project assets. The separate recreation study includes attributed Apple excerpts; source videos and font files are not bundled.
