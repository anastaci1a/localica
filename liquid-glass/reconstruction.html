Reproduce

Use Python 3.11+ and the pinned dependencies in a private virtual environment. Linux DejaVu Sans affects captions only. Download original HD videos privately as 219-hd.mp4 and 284-hd.mp4 using sources.json; replay checks hashes and decoded dimensions.

Comparison figures declare caption bounds in comparison-panels.json. Update those dimensions with each resized figure so wipe mode preserves the full rendered body.

From the repository root:

python3 docs/liquid-glass/experiments/reconstruction/verify-recipes.py
python3 docs/liquid-glass/experiments/reconstruction/settled.py /private/videos /private/replay
python3 docs/liquid-glass/experiments/reconstruction/motion.py /private/replay /private/motion

The second command renders the five historical frozen recipes, native-resolution outputs and scores; current toolbar/switch commands are linked in their model sections. Add --assets docs/liquid-glass/assets to update public comparison figures. The third recreates the playback translation video/GIF and requires ffmpeg. Neither refits or modifies the live lab; no GPU is needed. The portable specification is the equations and dimensionless parameters; commands fix one sampling implementation. Codec/library versions can change encoded media bytes.

Background recovery uses SIFT/RANSAC registration for dune/text scenes and smooth uncovered-page fits elsewhere. Inputs are quantized to eight-bit intermediate images to match calibration. Hidden text/track endpoints remain estimates. The historical settled stills use four samples per axis; current studies declare their native sampling in their records. Sampling is bilinear, filter boundaries reflect, and coverage is separate.

The play mask contains coverage only. In that historical toolbar replay, glyph colors and distant exterior remain shared Apple imagery; the current revision uses independent vectors and a generated shadow. A ten-pixel contact band uses the recovered source plus a normalized low-frequency exterior residual; it is unscored. Motion uses the playback recipe at two samples per axis and omits shadows. Archived MP4/GIF encoding is separate from numerical still replay.

Historical search tools and results.json retain alternative models; they are not the selected recipes/current scores. Search again only in a separate directory. Tool consistency, Apple similarity and Android performance require different checks.
